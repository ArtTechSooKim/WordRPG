## 3. 필드 타일 (P1) — 지역 2곳

- 규격: **32×32 (또는 16×16) 정사각형, 옆 칸과 이어 붙였을 때 이음새가 안 보이게**
- 파일 이름: `Assets/Resources/Art/NinjaAdventure/Tiles/{Meadow|Library}_{Floor|Grass|...}[_done].png` — 스크립트가 바닥 + 물건을 합성해 만든다
- **아래 표는 #17에서 모두 ☑ (Ninja Adventure)**. 물가 테두리·이어지는 길 모양(오토타일)은 아직 없음 — 한 칸짜리 그림 반복

**초원 (meadow)** — 아래쪽 마을 + 풀밭 + 연못

| ☐ | 종류 | 맵 글자 | 설명 |
|---|---|---|---|
| ☑ | `floor` | `.` | 흙길 |
| ☑ | `grass` | `,` | **진한 풀숲 — 몬스터가 나오는 칸이라 길과 확실히 구분돼야 함** |
| ☑ | `wall` | `#` | 나무 (지나갈 수 없음) |
| ☑ | `water` | `~` | 연못 물 (가능하면 물가 테두리 변형 4~8종) |
| ☑ | `door` | `D` | 동굴 입구 (던전으로) |
| ☑ | `fountain` | `F` | 회복의 샘 |
| ☑ | `chest` / `chest_open` | `C` | 보물상자 닫힘 / 열림 |
| ☑ | `altar` | `E` | 진화의 제단 (보라색 수정) |
| ☑ | `shop` | `S` | 상점 노점 (차양 있는 가판대) |
| ☐ | (선택) 마을 장식 | — | 집, 울타리, 꽃 — 지금 맵엔 없음, 추가하면 맵에 글자도 추가 필요 |

**잊혀진 서고 (library)** — 던전

| ☐ | 종류 | 맵 글자 | 설명 |
|---|---|---|---|
| ☑ | `floor` | `.` | 오래된 나무 마루 |
| ☑ | `grass` | `,` | **흩어진 책장·종이 더미 — 몬스터가 나오는 칸** |
| ☑ | `wall` | `#` | 책장 |
| ☑ | `water` | `~` | 잉크 웅덩이 |
| ☑ | `door` | `D` | 서고 출입문 (초원으로) |
| ☑ | `fountain` | `F` | 서고 버전 회복 지점 (예: 빛나는 독서대) — 초원 샘 재사용도 가능 |
| ☑ | `chest` / `chest_open` | `C` | 서고 분위기 상자 (예: 낡은 트렁크) — 초원 상자 재사용도 가능 |

- ☑ 글꼴 크기 체계 (제목 / 본문 / 작은 글씨)
- ☑ 버튼 4상태: 기본 · 누름 · 비활성 · 강조 — 둥근 모서리는 코드로 생성 (9-slice 이미지 내보내기 필요 없음)
