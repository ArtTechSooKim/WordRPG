사용자: "스킬 이펙트가 BGM에 많이 묻힘, 1.2배 줄인 것을 되돌려서 묻히지 않게 · 이음새는 초원만 너무 차이남, 지금보다 덜 평온하게"
- 기술 소리: TONE을 #165 값으로 되돌림 + 깎은 뒤 최고 음량까지 최대 3dB 들어 올림 (`LIFT_MAX`)
- 곡 음량: 전투 -19 → -21, 보스 -18 → -20 LUFS (#166에 Claude가 올린 값이 묻힘을 키웠음)
- 잰 값 (게임 음량, 300~4000Hz, 가장 큰 곡 숲 보스 기준): 베기 -3.3 → +2.7dB · 채찍 -2.9 → +3.7 · 형광펜 -2.9 → +3.0 · 할퀴기 -2.6 → +3.1 · 포자 -4.3 → +1.3 (가장 낮음). 실제 들리는 것은 사용자 확인
- 초원 이음새가 튄 원인: 겹치는 두 구간이 닮으면 합이 커지는데(같은 소리면 +3dB) 같은 비율로 섞었음. 닮은 정도만큼 줄이도록 고침(`make_loop_even`) + 시작 자리까지 찾고 파형까지 맞춰 고름(`find_loop_careful`). 초원 곡에만 켬 — 다른 곡은 사용자가 이음새를 확인해서 반복 자리를 안 바꿈
- 초원 곡: 같은 곡을 빠르게 (크레딧 안 듦). 빠르기를 올리면 음도 같이 올라감. 후보 = `Builds/music_pilot/round5_듣기/` (A 1.10배 · B 1.18배 · C 1.18배 + 8비트 살짝). 곡이 두 바퀴 돌고 이음새는 한 바퀴 끝 (A 43.6초 · B·C 40.7초). **사용자가 B를 고름 (#168)** → `Tools/prepare_music.py`의 TWEAKS
- 기술 소리는 이 값으로 사용자가 '딱 좋음' (#168)

## 게임에 넣는 방법 (코드 — 곡이 정해진 뒤)

- (#166 완료) 테마 표 `ThemeLooks`에 전투곡·보스곡 칸, `Sound.PlayBattleMusic`이 그 칸을 봄. 파일이 없으면 공용 곡으로. 새 곡 = `Music` 맨 뒤(Battle…·Boss…로 시작) + 표 + `Tools/prepare_music.py` 표
- `Music` 열거형은 맨 뒤에 추가, 새 테마는 `ThemeTableTests`가 빠진 칸을 잡음
- 반복 이음새를 ffmpeg로 처리 (끝과 처음을 겹치기, A처럼 끝에 무음이 있으면 먼저 잘라냄)
- 음량을 지금 곡들에 맞춤 (전투곡 -22.5 LUFS, #163)
- 사막 전투는 A·B 2곡을 번갈아 (한 지역에 곡이 여러 개여도 되게 칸을 만듦)
- 파일은 `Resources/Audio/Licensed/` — 공개 저장소에 올리지 않음(.gitignore). **깃에 없으니 따로 백업 필요**. 복사본 빌드에도 복사할 것
- 앱 크기: 19곡 × 60초 ≈ 16MB 증가 예상 (지금 곡 1개 60초 안팎 0.7~1MB 기준 · 안드로이드 AAB가 지금 49MB)
