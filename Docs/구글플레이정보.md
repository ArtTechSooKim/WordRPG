## 자세한 설명 (4,000자)

앱스토어 설명의 1.2판과 같은 내용. 애플·앱스토어를 말하는 곳 없음.

```
공부하려고 켜는 게임이 아니라, 하다 보니 영단어를 외우고 있는 게임.

영단어RPG는 영단어 문제를 맞혀야 기술을 쓸 수 있는 턴제 RPG예요. 초원에서 시작해 잊혀진 서고와 숲, 메아리 정글, 어두운 밀림 동굴을 탐험하며 몬스터와 싸우고, 성유물을 모아 강해지다 보면 어느새 단어가 머리에 남아 있어요.

■ 싸우면서 외워요
• 기술마다 4지선다 영단어 문제 — 맞히면 기술 발동, 빨리 맞히면 크리티컬
• 단어를 연속으로 맞히면 콤보, 강도를 올리면 더 센 공격
• 처음 만난 단어는 뜻을 먼저 보여 주고, 틀린 단어는 오답 노트에 남아 곧 다시 나와요
• 숙련도에 맞춰 잊을 때쯤 다시 나오는 복습

■ 교육과정 필수 어휘
• 교육부 2022 개정 영어과 교육과정의 기본 어휘 중 자주 쓰이는 단어 450개 (초원·서고 150 · 숲·정글·동굴 300)
• 초원·서고는 중·고등 공통 어휘, 숲·정글·동굴은 한 단계 위 어휘
• 단어 도감 — 모을수록 기념 징표와 보상

■ 모험
• 넓은 맵, 숨은 보물상자, 미니맵과 지도
• 보스 방 열쇠를 찾고 새 단어로 힘을 모아 보스에 도전
• 성유물 13개를 모아 장착하고 강화 — +3이 되면 각성
• 어두운 밀림 동굴: 단어로 글자 반딧돌을 밝히며 어둠 속을 탐험
• 메아리 정글: 뗏목을 타고 유적을 탐험하며 첫 동료 아라를 만나요
• 보스 결정타 연출, 기술마다 다른 전투 연출
• 수련장에서 허수아비와 싸우며 도감 속 단어만 복습
• 보스를 이기면 쉼터에 놓이는 '사전' — 하루 한 번 새 단어

■ 편하게
• 한 손으로 하는 세로 화면, 가상 스틱
• 자동 저장 — 언제 꺼도 이어서
• 광고 없음, 개인정보 수집 없음

■ 무료로 즐기는 범위
초원과 잊혀진 서고(첫 던전과 보스)까지 무료예요. 숲과 메아리 정글, 어두운 밀림 동굴, 앞으로 추가될 지역은 정식판(한 번 결제)으로 열려요.
```

## 앱 콘텐츠 설문 (예상 답 — 제출 전에 사용자 확인)

- **개인정보 처리방침**: 위 URL. 올리기 전에 gh-pages의 privacy·index 페이지에 Google Play 결제 문구를 더함 (지금은 Apple만 적혀 있음)
- **광고**: 없음
- **앱 액세스**: 일부 기능 제한 있음 → 심사자용 안내: 숲부터는 정식판(인앱 구매). 초원·서고는 로그인 없이 바로 플레이. 콘솔의 라이선스 테스트로 구매 가능
- **콘텐츠 등급(IARC)**: 앱스토어 설문과 같은 사실로 답함 — 만화 같은 비현실적 폭력(귀여운 도트 몬스터, 피 표현 없음), 도박·루트박스 없음(보물상자는 돈으로 사지 않음), 사용자 간 소통 없음, 위치 공유 없음, 디지털 구매 있음
- **타겟층**: 13세 이상 (앱스토어 13+와 맞춤. 13세 미만을 넣으면 가족 정책 조건이 붙음 — 사용자 결정)
- **데이터 보안**: 수집·공유하는 데이터 없음 (계정 없음, 분석·광고 SDK 없음, 진행 기록은 기기에만). 결제는 구글이 처리. 데이터 삭제 요청 칸은 계정이 없어 해당 없음
- **뉴스 · 코로나 · 금융 · 건강 · 정부**: 해당 없음
- **내보내기(국가)**: 앱스토어처럼 전체 — 사용자 결정
