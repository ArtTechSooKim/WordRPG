 (참고) Mac에서 직접 올리는 방법 — Xcode가 깔리는 Mac이 생기면
 -------------------------------------------------------------
 Windows에서 만든 Xcode 프로젝트(WordRPG-iOS-버전.zip)를 Mac에서 열어 서명하고 올린다.
 zip은 Windows의 F:\GameProject\WordRPG\Builds\ 폴더에 있음 (USB·클라우드 드라이브 등으로 Mac에 옮기기)
 앱 고유 이름(번들 ID): com.arttechsoo.wordrpg   /   앱스토어 커넥트 앱 번호: 6818805727


 1. Mac 준비 (처음 한 번)
 -----------------------
  - Mac의 App Store에서 Xcode 설치 (무료, 용량이 큼). 처음 켤 때 추가 구성 요소·iOS 설치를 물으면 설치
  - Xcode > Settings(설정) > Accounts(계정) > 왼쪽 아래 + > Apple ID → 애플 개발자 계정으로 로그인


 2. 프로젝트 열기
 ---------------
  - zip을 더블클릭해서 풀기 → WordRPG-iOS 폴더
  - 폴더 안의 Unity-iPhone.xcodeproj 더블클릭 → Xcode가 열림


 3. 서명 설정
 -----------
  - 왼쪽 맨 위 파란 아이콘 'Unity-iPhone' 클릭 → 가운데 TARGETS 목록에서 'Unity-iPhone' → 위쪽 'Signing & Capabilities' 탭
  - 'Automatically manage signing' 체크 → Team = 내 개발자 팀 선택
  - Bundle Identifier가 com.arttechsoo.wordrpg 인지 확인 (빨간 오류가 없으면 됨)


 4. 내 아이폰에서 먼저 실행해 보기 (권장)
 ------------------------------------
  - 아이폰을 케이블로 Mac에 연결 → 아이폰에서 '이 컴퓨터를 신뢰' 누르기
  - 아이폰 설정 > 개인정보 보호 및 보안 > 개발자 모드 켜기 (아이폰이 다시 켜짐)
  - Xcode 위쪽 가운데 기기 목록에서 내 아이폰 선택 → 왼쪽 위 ▶ 버튼 (첫 빌드는 10~20분)
  - 확인할 것: 한글 글꼴, 스틱 조작감·달리기, 화면 위(노치)·아래(홈 막대)에 가리는 곳, 소리(무음 스위치)·진동,
    앱을 내렸다가 다시 열었을 때 이어지는지


 5. TestFlight에 올리기
 ---------------------
  - 기기 목록에서 'Any iOS Device (arm64)' 선택 → 메뉴 Product > Archive (몇 분~20분)
  - 끝나면 Organizer 창이 열림 → 방금 만든 항목 선택 → Distribute App → 'App Store Connect'(또는 'TestFlight & App Store')
    → 나머지는 기본값으로 Next / Upload
  - 10~30분 뒤 앱스토어 커넥트 > 앱 > TestFlight 에 빌드가 나타남 ('처리 중' → 완료).
    암호화(수출 규정) 질문은 빌드에 미리 '사용 안 함'으로 적어 두어서 따로 안 물어봄
  - TestFlight > 내부 테스트 > + 로 그룹을 만들고 나를 테스터로 추가 → 아이폰에 'TestFlight' 앱을 깔면 영단어RPG를 설치할 수 있음


 6. 다시 올릴 때
 --------------
  - 같은 빌드 번호는 다시 올릴 수 없음. Claude에게 "빌드 번호 올려서 아이폰 빌드 다시 만들어 줘" 라고 하면 새 zip을 만듦
    (직접 하려면 Unity > Edit > Project Settings > Player > iOS > Other Settings > Build 를 1 올린 뒤 WordRPG > Build > iOS Xcode 프로젝트)


 문제가 생기면
 ------------
  - Xcode 오류 화면을 캡처해서 Claude에게 보여 주기
  - 'Permission denied'(권한 없음) 오류가 나면: Mac의 '터미널' 앱에서  chmod -R u+x  를 입력하고 한 칸 띄운 뒤
    WordRPG-iOS 폴더를 터미널 창에 끌어다 놓고 Enter → Xcode에서 다시 빌드
