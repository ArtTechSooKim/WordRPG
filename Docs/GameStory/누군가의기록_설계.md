## 게임 데이터 (만들 때)

- 세이브 칸을 더하지 않음: 상자를 열면 아이템으로 들어오고, 선명한 줄은 찾은 단어로 바로 계산
- 아이템: `ItemKind` 맨 뒤에 새 종류, 새 id (`journal_...`, 출시 뒤 바꾸지 않음). 단어장과 연결 → Refresh Game Database
- 상자: 있던 상자의 내용물은 바꾸지 않음 (이미 연 사람이 못 얻음). 맵에 새 상자를 더함 → 상자 수 = 내용물 수, 맵 상수와 에셋을 같이 고침. 상자 id가 위치 기준이라 예전 세이브에서도 새 상자로 보임
- 단어 CSV: `example`·`example_meaning` + `story`(기록 안의 순서, 비우면 예문만) + `story_heading`(묶음 제목). 원문 `누군가의기록_문장.tsv` → `python Tools/journal_lines.py --apply`
- 문장은 도감 상세와 전투 단어 카드에도 그대로 나옴. 가장 긴 문장(64자)까지 들어가는 것을 캡처로 확인
- 흐림: 그림 한 장 `Resources/UI/Journal/smudge.png` (`python Tools/make_journal_smudge.py`)에서 줄마다 잘라 씀. 글자를 그리지 않으므로 읽을 수 없고, 줄이 많아도 가벼움
- 종이 색은 `Palette`에 새로 더함 (시안 값: 종이 233,220,192 / 글 58,44,28 / 해석 109,90,66 / 단어 154,74,18)

## 문장 쓰는 규칙

- 한 줄만 봐도 말이 되게: 전투 카드에서는 한 문장씩, 무작위 순서로 보인다
- 단어는 단어장 꼴 그대로, 등록된 뜻으로 (2.0 빈칸 문제에 그대로 쓰려고)

- 원문 `누군가의기록_문장.tsv`

## 일기 줄거리 (안)

글자를 가르치던 사람의 일기. 첫 줄은 "이 일기의 제목은 내 이름이었지만, 잉크가 바랬다."

1. 평범한 마을: 동생, 사전을 가진 옆집 어르신, 샘, 축제
2. 첫 빈칸: 동생의 이름이 들리지 않고 글자가 밤사이 사라짐
3. 마을이 흔들림: 의회·위원회·법, 모두 잊어 감
4. 어르신이 말을 잃음: 사전을 마을 위 상자에 넣어 둠 (게임의 백과사전 상자)
5. 동생과 함께 서고로 떠남
6. 길 위: 말을 잃어 가는 세상
7. 서고: 찢긴 쪽과 용 비늘 자국, 커다란 인물을 쫓아간 동생, 잠긴 문 (게임의 보스 문)
8. 마지막 쪽: 일기를 그 앞 상자에 남김. 끝 줄 "이 줄을 읽고 있다면, 내 일기는 성공한 것이다."

## 생존일지 줄거리

분위기가 일기와 다른 웃긴 기록. 부처에서 보낸 지도 제작자가 노새와 함께 숲에서 길을 잃고도 서류 형식을 지킨다.
출발 전 → 숲 (이정표를 뒤섞는 너구리) → 정글 (바위 시장, 두꺼비의 혀, 유적) → 동굴 → 벽의 글 "모든 말의 기원은 사막 아래에 있다" → 노새가 일지를 들고 돌아감 (그래서 숲 야영지 상자에 있음). 끝 줄 "이걸 읽고 있다면, 당신이 내 증인이다."
