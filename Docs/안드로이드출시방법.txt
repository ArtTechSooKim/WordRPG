 [먼저 알아 둘 것] 새 개인 계정의 테스트 조건
------------------------------------------------------------------
 2023-11-13 이후 만든 '개인' 개발자 계정은 바로 정식 출시를 할 수 없다.
   1) 비공개 테스트에 테스터 12명 이상이 14일 동안 계속 참여
      (중간에 빠졌다 다시 들어오면 14일이 처음부터)
   2) 콘솔 대시보드에서 [프로덕션 신청] → 구글 검토 (보통 7일 이내, 더 걸릴 수도 있음)
   3) 그다음 정식 출시 심사
 → 계정이 준비된 날부터 정식 출시까지 약 4주.
 구글 안내는 '개인 계정'만 말하고 조직 계정(사업자)은 언급이 없음 — 조직 계정으로 만들면 콘솔에서 조건을 확인할 것.

 그래서 앱스토어와 같은 날 내는 방법:
   - 구글 [프로덕션 신청]이 승인될 때쯤 앱스토어 1.2를 '수동 출시'로 바꿔 심사 제출
   - 둘 다 승인되면 같은 날 출시 버튼
   - 그동안 앱스토어 1.2는 기다림 (사용자 결정: 같이 올리기)

 [처음 한 번] 사용자가 직접 할 일
------------------------------------------------------------------
 1. play.google.com/console 에서 개발자 계정 만들기: 등록비 25달러(한 번), 신원 확인
 2. 결제 프로필 만들기 (정식판을 팔려면 필요 — 콘솔 > 설정 > 결제 프로필)
 3. 앱 만들기: 이름 영단어RPG, 게임, 유료 아님(무료 + 인앱 구매), 기본 언어 한국어
    패키지 이름은 처음 AAB를 올릴 때 com.arttechsoo.wordrpg 로 정해짐 (바꿀 수 없음)
 4. 앱 서명: 'Google Play 앱 서명' 그대로 사용 (기본값). 우리가 가진 열쇠는 '올림 열쇠'
 5. 테스터 12명 이상의 구글 계정 이메일 모으기 (친구들) — 14일 동안 빠지지 않게 부탁
 6. 공개 문의 이메일 정하기 (스토어에 공개됨)

 [올릴 때마다] 빌드 (Claude에게 "구글플레이 빌드해 줘")
------------------------------------------------------------------
 1. ProjectSettings의 AndroidBundleVersionCode를 +1 (올릴 때마다 전보다 커야 함. 처음 = 1)
 2. 복사본에 복사 (사용자 프로젝트의 플랫폼을 바꾸지 않으려고):
    robocopy F:\GameProject\WordRPG F:\_WordRPG_androidcopy /MIR
      /XD Library Temp Logs Builds .git UserSettings obj _캡처 *-utc Licensed _소리후보_새단어
      /XF .git AuthKey_* *.p8 *.pdf *.keystore *.jks
    (Licensed = 유료 소리. 복사본에 이미 있으니 지우지 않게 뺌. 복사본을 새로 만들면 main 폴더에서 Assets/Resources/Audio/Licensed를 복사)
 3. 빌드 (복사본에서, Git Bash):
    export WORDRPG_ANDROID_KEYS="F:/_WordRPG_keys/android-upload.properties"
    "C:/Program Files/Unity/Hub/Editor/6000.3.11f1/Editor/Unity.exe" -batchmode -quit -projectPath "F:/_WordRPG_androidcopy"
      -buildTarget Android -executeMethod WordRPG.EditorTools.MobileBuild.BuildAndroidAab -logFile build-android.log
    → F:/_WordRPG_androidcopy/Builds/Android/WordRPG-1.2.aab
    휴대폰에 바로 깔아 볼 APK는 BuildAndroidApk (열쇠가 없어도 됨, 스토어에는 못 올림)
 4. 검사: python Tools/check_android_bundle.py F:/_WordRPG_androidcopy/Builds/Android/WordRPG-1.2.aab
    (패키지 · 대상 API 36 · 게임 표시 · 뒤로 가기 · 결제 권한 · 64비트 · 16KB 페이지 · 크기)
 5. 콘솔 > 테스트 > 내부 테스트 > 새 버전 → AAB 올리기 (처음은 직접. 나중에 서비스 계정을 만들면 Claude가 자동으로)

 [상품] 정식판 등록
------------------------------------------------------------------
 콘솔 > 수익 창출 > 인앱 상품 > 상품 만들기 (AAB를 한 번 올려야 메뉴가 열림)
   상품 ID: com.arttechsoo.wordrpg.full  ← 앱스토어와 똑같이. 바꾸지 말 것
   이름: 정식판 / 가격: 앱스토어와 같게 / 활성화
 결제 시험: 콘솔 > 설정 > 라이선스 테스트 에 시험할 계정 추가 → 그 계정은 실제로 돈이 나가지 않음
