## 2. 전투

- **주인공 1 vs 적 1~3**. 한 라운드 = 주인공이 **[기술 선택 → 단어 문제 → 결과]** (또는 상처약) 후 적 전원 행동
- 기술 = **기본 기술 1개(휘두르기, 영→한, 항상) + 기술 칸 3개** (최대 4개). 기술 칸에는 끼운 성유물의 기술이나 기술문서로 배운 기술이 들어간다.
  버튼에 어디서 온 기술인지 표시 ("깃펜 · 공격 14 · 적 전체", "기술문서 · 공격 30 · 적 1체") — 아래 '기술문서'
- **정답** → 기술 발동. **3초 이내**면 크리티컬 ×1.5
- **오답 / 10초 초과** → 기술 실패, 단어는 오답 노트로. (UI는 정답을 꼭 보여줘서 학습 순간으로 만든다)
- **강한 기술일수록 어려운 문제**: 기본 기술은 영→한(쉬움), 성유물 기술은 대부분 한→영(어려움) — 어떤 성유물을 끼우는지가 곧 난이도 선택
- **상처약** (2026-10-02): 기술 대신 맨 아래 [가방 — 상처약 쓰기]. 문제 없이 HP를 회복하고 한 턴을 쓴다 (적은 행동함). HP가 가득이면 잠금
- **처음 보는 단어**는 '새 단어' 카드로 뜻을 먼저 보여준 뒤 영→한으로 출제. 카드 왼쪽 위에 '발견!' 도장이 찍히고 단어 뒤가 금빛으로 반짝이며
  짧은 발견 징글(나오는 동안 배경 음악을 잠깐 멈춤)이 울린다 (2026-10-03 사용자 의견: '발견!' 느낌)
- **공격 강도** (2026-10-03 사용자 아이디어 — 위험과 보상): 공격 기술을 누르면 강도를 고른다 (회복·보호막 기술은 바로 문제)

  | 강도 | ×1 | ×1.2 | ×1.5 | ×2 (최대) |
  |---|---|---|---|---|
  | 맞혀야 할 단어 | 1개 | 2개 연속 | 3개 연속 | 4개 연속 |

  - 단어를 하나씩 이어서 낸다 (단어마다 10초 타이머, 처음 보는 단어면 새 단어 카드). **하나라도 틀리거나 시간 초과면 이번 턴 공격 실패** (적은 행동)
  - 맞힌 단어는 하나하나 콤보에 더해진다 → ×2를 연속으로 성공하면 콤보도 빨리 오른다 (최종 피해 = 강도 × 콤보 보너스)
  - 크리티컬은 그 기술의 단어를 **모두** 3초 안에 맞혔을 때만. 버튼마다 '예상 피해'(랜덤·크리티컬 빼고, 다 맞혔을 때 쌓일 콤보 포함)
  - 문제 화면 오른쪽 위 배지 "×1.5 ●○○ 1/3", 기술이 발동하면 주인공 위에 "×1.5!"와 기록 "주인공의 잉크 뿌리기 ×1.5!"
  - 배율은 BattleConfig.intensityMultipliers (Figma 'Intensity Button', 'Chain Badge', '전투 — 강도 고르기', '전투 — 연속 문제 진행')
- **연속 정답 콤보** (2026-10-03 사용자 아이디어 — 타격감): 연속으로 맞히면 글자가 크게 찍히듯 나타났다가 떠오르며 사라지고,
  단계마다 아군 공격 기술 피해 **+5%** (회복·보호막은 그대로). 효과음 음높이도 단계마다 올라가고 피해 숫자도 커진다

  | 연속 정답 | 2 | 3 | 4 | 5 | 6 | 7 이상 |
  |---|---|---|---|---|---|---|
  | 글자 (색) | Combo! (흰) | Good! (초록) | Very Good! (하늘) | Excellent! (금) | Outstanding! (주황) | Exceptional! (분홍) |
  | 추가 피해 | +5% | +10% | +15% | +20% | +25% | +30% |

  - 오답·시간 초과면 0부터. 상처약은 문제가 없으므로 끊기지 않음. **전투가 끝나도 이어짐** (필드를 돌며 계속 맞히면 계속 쌓임).
    단 **전투가 끝나고 3분이 넘게 지나 다음 전투를 시작하면 0부터** (2026-10-03 사용자 결정). 시간은 전투가 끝난 뒤부터 재므로
    전투가 3분 넘게 길어져도 도중에 끊기지 않는다 (Combo.Expiry, GameSession.StartBattleCombo/EndBattleCombo).
    세이브에는 넣지 않아 게임을 다시 켜면 0부터. 단계당 %는 BattleConfig.comboBonusPerStep (Figma 'Combo Text', '전투 — 연속 정답 콤보')
- **보스 결정타** (2026-10-07 사용자 요청 — 타격감): 보스전에서 아군이 보스를 쓰러뜨리는 **마지막 타격**(여러 번 때리는 기술이면 마지막 한 번)만
  하얀 번쩍임 → 느린 화면(가장자리 어둡게, 적 칸만 밝게 · 보스 카드 커지며 흔들림 · 3배 느린 큰 폭발 · 낮은 음 크리티컬+타격 · 진동)

## 3. 단어 숙련도

| 상황 | 결과 |
|---|---|
| 정답 + 처음 만남 | → 학습 |
| 정답 + 복습 시기 도래 | 한 단계 상승 |
| 정답 + 복습 시기 전 | 변화 없음 (몰아 풀기로 숙련도가 오르지 않게) |
| 정답 + 오답 노트에 있음 | 단계 유지, 오답 노트에서 빠짐 |
| 오답 | 한 단계 하락(최저 '학습'), 오답 노트, 즉시 출제 대상 |

복습 간격: 학습 5분 → 복습 1일 → 숙련 3일 → 완전 숙련 7일

**출제 우선순위**: ① 오답 노트 ② 복습 시기 된 단어 ③ 새 단어 (학습 중 단어가 12개 미만일 때) ④ 본 단어 중 숙련도 낮은 것.
최근 4문제에 나온 단어는 건너뜀. 4지선다 오답 보기는 같은 품사 우선, 뜻이 겹치는 단어(acquire/obtain)는 제외.

## 4. 주인공 · 성유물 · 적 (임시 데이터)

**주인공**: Lv1 HP 60 / 공격 14 / 방어 10, 레벨당 +8 / +3 / +2. 시작 Lv3. 능력치 = 레벨 능력치 + **끼운 성유물 보너스**.
레벨업 필요 경험치 = 10 + 10 × 현재 레벨, 최대 Lv30.

**성유물** (여러 개 모으고 3칸에 골라 끼움 — 사용자 결정 '수집형'). 새로 얻으면 빈 칸에 바로 끼우고, 칸이 가득하면 가방 > 성유물에서 바꿔 끼운다.
강화: 성유물 제단에서 재료 + 골드로 +1 (최대 +5). 비용 +1:1개·30G / +2:2개·60G / +3:2개·90G / +4:3개·120G / +5:3개·150G.
**+3에서 각성** → 기술이 더 강한 기술로 바뀐다 (각성 연출).

| 성유물 | 얻는 곳 | 역할 | 기술 (각성 후) | 보너스 (강화당) | 강화 재료 |
|---|---|---|---|---|---|
| 깃펜 (예전 펜촉이) | 시작 | 공격형 | 잉크 뿌리기 적 전체 14 → 잉크 폭풍 22 (한→영) | 공격 +4 (+2) | 빛나는 잉크 |
| 백과사전 (예전 책껍질) | 초원 마을 위 보물상자 | 방어형 | 책 방패 4 → 백과 방벽 10 (한→영) | HP +10 방어 +4 (HP +4 방어 +1) | 단단한 표지 |

## 5. 저장 (세이브/로드)

- **자동 저장만** 있음 (저장 버튼 없음): 문제에 답할 때마다, 전투 결과 후, 앱이 백그라운드로 갈 때·종료될 때
- 앱을 켜면 **타이틀 화면** (2026-10-06 사용자 결정): **"화면을 터치하세요"** — 어디든 누르면 바로 이어하기, 저장이 없으면 새 게임.
  저장 요약 카드(지역 · 주인공 레벨 · 성유물 수 · 발견한 단어 · 전투 수). 타이틀 그림은 가운데 주인공 + 둘레에 끼운 성유물
  - 처음부터 다시 하기는 **설정에서만**, 실수 방지로 **두 번 확인** ("처음부터 다시 할까요?" → "정말 지울까요?")
  - 타이틀에서 시작하기 전에는 저장하지 않는다 (켜고 바로 끄거나, 저장을 지운 뒤 꺼도 빈 세이브가 생기지 않게)
- 필드에서는 첫 알림에 "이어하기 — 발견한 단어 N개, 전투 N승 N패"
- 저장 내용 (세이브 v2): 주인공(레벨, 경험치, HP), 모은 성유물(id, 강화 단계, 끼운 칸), 골드·아이템, 단어별 학습 기록(숙련도, 다음 복습 시각, 오답 노트, 맞힌/틀린 횟수, **발견 시각**), 누적 전적, 위치·연 상자·보스·탐험 기록
  - v1(몬스터 파티 시절) 세이브는 파티의 가장 높은 레벨을 주인공 레벨로 바꾸고 시작 성유물을 준다 (단어 기록·소지품은 그대로)
- 전투 도중 앱이 꺼지면: 그때까지 푼 단어 기록과 HP는 남고, 전투 자체는 없던 일이 됨. 쓰러진 상태로 저장됐으면 불러올 때 회복
- 안전장치: 임시 파일에 쓴 뒤 교체 + 직전 세이브를 `.bak`으로 보관. 세이브가 깨지면 백업에서 복구, 둘 다 깨지면 지우지 않고 `.corrupt_날짜`로 보관 후 새 게임
- 세이브에서 성유물을 찾을 수 없으면(삭제·id 변경) 그것만 빼고, 하나도 없으면 시작 성유물로 채움 — **단어 학습 기록은 항상 유지**
- **처음부터 다시 하기**: 설정 화면(필드 오른쪽 [설정] 또는 타이틀 오른쪽 위) → 빨간 버튼 → 1차 [처음부터] → 2차 [지우기] → 타이틀로
- **튜토리얼 다시 보기**: 설정 화면 → 본 안내를 지우고 필드 안내부터 다시 (타이틀에서 누르면 바로 시작)
- **설정**(배경 음악·효과음 음량, 진동)은 세이브와 따로 기기에 저장 (PlayerPrefs) → 저장 데이터를 지워도 설정은 남음.
  소리는 아직 없어서 음량은 값만 저장. 진동은 오답일 때 휴대폰에서만
- 위치: PC는 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\영단어RPG\save.json`, 아이폰은 앱의 Documents 폴더(아이클라우드 백업에 포함).
  ⚠ 회사명·앱 이름·번들 ID를 바꾸면 저장 위치가 바뀌어 기존 세이브를 못 찾음 (출시 전에 확정할 것)

## 6. 단어 도감 (구현됨 — 사용자 아이디어, 2026-10-01)

단어를 몬스터 도감처럼 "발견해서 채우는" 구조. 전투 화면 상단의 [도감] 버튼으로 연다
(스킬 선택 중·결과 화면에서만. 문제 풀이·연출 중에는 잠김).

- **발견** = 한 번이라도 문제로 만난 단어 (맞히든 틀리든). 미발견은 "???"로 가려 표시
- 전투의 '새 단어' 카드 = 도감 등록 순간 ("발견!" 도장 + "새 단어 · 도감 등록 37/100")
- 목록: 번호 + 단어 + 숙련도 별 (학습 ★☆☆☆ ~ 완전 숙련 ★★★★), 숙련도별 행 색상
- 단어를 누르면 상세: 뜻, 품사, 예문, 별 등급, 맞힘/틀림 횟수, 다음 복습까지 남은 시간, 발견일
- 상단: 지역 완성률 바, "37 / 100 발견 · 완전 숙련 N개", 완성 보상 안내

**지역 완성 보상 (사용자 결정)**: 도감 100% → **지역 징표(기념물) + 골드**, 지역당 한 번, 자동 지급
(결과 화면에 "★ 초원 도감 완성!" 표시). 강화 재료·성유물은 도감 보상에 넣지 않고 **다른 경로**로 얻는다
(현재는 적 드롭, 이후 필드 보물상자·상점 등 — 아직 미구현).

| 지역 | 징표 | 골드 |
|---|---|---|
| 초원 | 네잎클로버 책갈피 (행운을 부르는 눌러 말린 네잎클로버) | 500 |

- 지역 정보는 단어장(WordDatabase)에 설정: regionId(세이브용, 바꾸지 말 것), regionName, 징표 아이템, 골드
- 새 지역 추가 절차: 단어 CSV 추가 → 단어장에 지역 정보·징표 지정 → 징표 아이템(종류 Keepsake) 만들기
  → `Refresh Game Database`. 빠뜨리면 RegionDataTests가 실패해서 알려줌
- 보상을 받은 뒤 콘텐츠 확장으로 단어가 늘어도 받은 징표·골드는 그대로 유지 (완성률 표시만 내려감)
- 보류: 발견 수 중간 마일스톤 보상 (10/25/50개 등) — 필요하면 추가

- **풀숲(진한 초록)**: 한 걸음마다 12% 확률로 야생 몬스터 조우. 조우 직후 4걸음은 안전 (연속 조우 방지)

  주요 길목(강 앞, 숲 오솔길)에는 반드시 지나가는 풀숲 띠를 둔다 (조우 없이 다음 지역까지 가지 않게)
- 조우하면 화면이 번쩍이고 전투 화면이 필드 위에 덮인다. 승리 → [계속 탐험]으로 같은 자리 복귀
  패배 → HP 회복 후 시작 위치(회복의 샘 앞)로 귀환, 페널티 없음
- **회복의 샘**: 앞에서 [확인] → HP 완전 회복
- **보물상자**: 앞에서 [확인] → 열림, 상자마다 한 번만 (세이브에 기록). **강화 재료·골드·성유물**이 나온다
- 화면 위: 지역 이름, 도감 발견 수, 골드 / 그 아래 주인공 배지 + 성유물 3칸 / 왼쪽 미니맵, 오른쪽 [도감][가방][설정]
- **미니맵·지도**: 지역의 글자 맵에서 자동으로 그린다 (한 칸 = 한 점) → 새 지역도 손대지 않고 바로 나옴.

  내 위치는 금테 흰 점. 미니맵을 누르면 큰 지도(범례 + 남은 보물상자 수 + 보스 상태)

  - **탐험 안개** (사용자 결정): 걸을 때 주변 반지름 3칸(원)이 밝혀지고, 안 가 본 칸은 어둡게 가린다 — 그 안의 상자·보스도 안 보임.

    - 나중 아이디어: 탐험 100% 보상, 지역을 처음 밝힐 때 알림
- 위치는 자동 저장 → 다시 켜면 마지막 자리에서 시작

**맵 만들기**: 지역 에셋(`Assets/Data/Areas/*.asset`, FieldArea)의 map 칸에 글자로 그린다

| 글자 | 뜻 |
|---|---|
| `.` | 길 |
| `:` | 잔디 (조우 없음 — 서고는 열람실 카펫, 숲은 이끼 땅) |
| `,` | 풀숲 (조우) |
| `#` | 나무 (막힘) |
| `~` | 물 (막힘) |
| `F` | 회복의 샘 (앞에서 [확인] → 회복) |
| `E` | 성유물 제단 (앞에서 [확인] → 성유물 강화 화면) |
| `S` | 상점 (앞에서 [확인] → 상점 화면, 지역의 shop에 연결된 상점. 이름표 = 상점 이름) |
| `B` | 보스 (앞에서 [확인] → 보스전, 지역마다 하나, 한 번 이기면 끝) |
| `D` | 출입구 — 밟으면 다른 지역으로. 연결은 exits 목록에 위→아래, 왼→오른 순서로 대응. openedByBossOf를 정하면 그 보스를 물리칠 때까지 막힘 |

| `P` | 시작 위치 (하나만) |

모든 줄의 길이가 같아야 하고, 상자 수 = 내용물 수, 시작 위치에서 모든 상자·샘에 갈 수 있어야 함 (AreaDataTests가 검사).
