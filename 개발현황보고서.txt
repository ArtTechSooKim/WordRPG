     → 진한 풀숲을 걸으면 야생 몬스터 조우 → 주인공 혼자 싸움. 기술마다 영단어 4지선다 → 이기면 그 자리로 복귀
       기술 = 기본 기술 '휘두르기'(쉬움) + 끼운 성유물마다 1개(대부분 어려움). 버튼에 어느 성유물 기술인지 나옴

     ★ 성유물 8개: 처음엔 '깃펜' 하나. 초원 호수 곶 끝 상자 = 백과사전, 서고 상자 = 등불·마법 지팡이, 서고 보스 = 기억의 성배,
       숲 상자 = 덩굴 채찍·시간의 모래시계, 숲 보스 = 세계수 잎. 얻으면 빈 칸에 바로 끼워짐, 칸(3개)이 가득하면 가방 > 성유물에서 바꿔 끼우기
     ★ 마을 샘 왼쪽 보라색 수정 = 성유물 제단: 재료 + 골드로 강화 (+5까지, 버튼 두 번). +3이 되면 '각성' — 기술이 더 강해짐
       (예: 깃펜 잉크 뿌리기 → 잉크 폭풍). 각성 연출: 단어가 반짝 → 알파벳 고리 → "각성 성공!"
     ★ 상점(샘 오른쪽 가게) = 상처약 30G(HP 40) · 큰 상처약 90G(HP 120). 강화 재료는 팔지 않음 → 전투·보물상자·보스로

       서고 보스를 물리치면 카메라가 숲 입구로 가서 덤불이 사라지는 모습을 보여 준 뒤 돌아옴
       숲: 입구 야영지(샘·상점·제단) → 굽이진 숲길 → 늪·부엉이 골짜기·버섯 공터 → 보스 헷갈너구리 Lv12
       적: 철자버섯·꼬부랑뱀·물음표부엉이 (Lv7~10). 숲 도감 완성 = 도토리 책갈피 + 700 골드
     ★ 새 단어를 처음 만나면 '발견!' 도장이 찍히고 짧은 발견 멜로디 (배경 음악은 잠깐 멈췄다가 다시)
     ★ 기술문서: 보스·보물상자에서 얻는 두루마리. 읽으면 새 기술을 배움 (전투 기술 = 기본 기술 + 기술 칸 3개 = 최대 4개)
       기술 칸이 가득이면 지금 기술 하나와 바꿔야 하고, 문서는 가방에 남아 언제든 다시 배울 수 있음 (가방 > 아이템 > [배우기])
       필통 방패 = 초원 서쪽 덤불 속 숨은 상자, 벼락치기 = 서고 보스, 형광펜 긋기 = 숲 보스
       빠진 성유물 기술은 가방 > 성유물 > [기술 넣기]. 등불 기술 '치유의 빛'은 '쪽잠자기'로 이름이 바뀜
     ★ 공격 강도: 공격 기술을 누르면 강도를 고름 — ×1(단어 1개) / ×1.2(2개 연속) / ×1.5(3개 연속) / ×2(4개 연속).
       버튼마다 예상 피해가 나오고, 하나라도 틀리면 그 턴 공격 실패. 맞힌 단어는 하나하나 콤보에 더해짐
     ★ 연속 정답 콤보: 2연속 Combo! → Good! → Very Good! → Excellent! → Outstanding! → 7연속부터 Exceptional!
       글자가 크게 찍혔다가 떠오르며 사라지고, 단계마다 공격 피해 +5% (최대 +30%). 틀리면 0부터, 전투가 끝나도 이어지지만
       전투가 끝나고 3분이 넘게 지나 다음 전투를 하면 0부터 (전투가 길어져도 도중엔 안 끊김)
     ★ 필드 길·물가에 테두리: 흙길 가장자리에 풀, 호수·강에 물결 물가 (예전 작품처럼). 새 타이틀 = 도트 초원 풍경 + 길 위의 주인공
     ★ 뒤로가기 (PC에서는 Esc 키, 안드로이드 폰의 뒤로 버튼): 열린 창(가방·설정·도감·지도·상점·제단·기술 배우기)을 닫고,
       아무 창도 없으면 "게임을 끝낼까요?" (끝내기 = 저장하고 종료). 전투 중에는 강도·대상·아이템 고르기 취소 (도망은 없음)
       아이폰은 뒤로 버튼이 없고, 앱이 스스로 꺼지면 안 되는 애플 규칙 때문에 '끝낼까요?'도 안 뜸 (홈으로 나가서 닫음)
